# Product

## Register

product

## Users

Mac users who need to locate, inspect, and safely manage files across a large home directory. They often know that a file was just created or changed but do not know its name or location. Their primary workflow is opening Cardinal, typing a plain-language fragment or choosing a visible filter, and acting on the result within seconds.

## Product Purpose

Cardinal is a local-first file search and filesystem activity tool for macOS. It succeeds when filename search, recent-file discovery, sorting, filtering, preview, exclusion management, and safe file actions remain immediate and understandable at million-file scale.

## Brand Personality

Fast, quiet, trustworthy. Cardinal should feel like a focused native Mac utility that disappears into the task.

## Anti-references

- Do not require Everything-style command syntax in the standard search field.
- Do not hide important controls inside unlabeled toggles or raw multiline settings fields.
- Do not block the interface while sorting or indexing a full result set.
- Do not use decorative dashboards, nested cards, glassmorphism, or excessive motion.
- Do not make Finder a required second step for routine file actions.

## Design Principles

1. Immediate by default: common searches and recent-file views must respond before the user notices computation.
2. Plain language first: advanced query syntax may exist internally, but everyday controls are visible and named.
3. Progressive power: start simple, reveal advanced filters only when requested, and keep active constraints visible as removable chips.
4. Safe direct action: preview, reveal, copy, rename, and move to Trash belong beside the result with clear recovery behavior.
5. Explain system state: indexing, exclusions, permissions, errors, and long operations must always show cause and progress.

## Accessibility & Inclusion

Target WCAG 2.2 AA where web technologies apply. Support full keyboard navigation, VoiceOver-friendly labels, visible focus, sufficient contrast, color-independent state cues, reduced motion, scalable text, and both light and dark system appearances.
